## 写文档的三条约定

1. **不写版本号。** 版本在 git 里。
2. **不新建文档，改现有的。** 冗余信息比信息缺失更贵——四份主文档已经是收敛后的结果，别再发散。
3. **改设计要说清"否决了什么"。** 只写结论的文档，半年后没人知道能不能推翻它。
