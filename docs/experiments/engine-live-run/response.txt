#### Step 3: Implement `monthly_total` Function

The `monthly_total` function will take a list of `Subscription` objects and a target month/year, then calculate the total amount due for all subscriptions active during that month.

Let's proceed with the implementation:

```python
# workspace/subscriptions.py

from dataclasses import dataclass
from datetime import date

@dataclass
class Subscription:
    customer_id: str
    start_date: date
    end_date: date
    monthly_price: float

def monthly_total(subscriptions, target_month: int, target_year: int) -> float:
    total = 0.0
    for subscription in subscriptions:
        start = subscription.start_date
        end = subscription.end_date
        if (start.year < target_year or (start.year == target_year and start.month <= target_month)) and \
           (end.year > target_year or (end.year == target_year and end.month >= target_month)):
            total += subscription.monthly_price
    return total
```
