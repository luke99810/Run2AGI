## 一、提交口径

初赛必交只有两项：500 字以内作品简介、方案 PPT/PDF。可执行 AgentTeams 代码包是可选项；若提交代码链接，必须如实披露“桌面协议 → 真引擎 → 真模型”已经跑通一次，但当前模型执行仍无工具循环、没有修改项目文件，不能把 fixture、Sidecar 自检或一次 one-shot 模型运行描述成完整 Agent 闭环。

C 在初赛前的目标不是完成安装交付，而是提供可核验的桌面产品原型、真实路径绑定与安全边界证据，为作品简介和 PPT 提供准确素材。
