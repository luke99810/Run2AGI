# Evolution Skill

Promote repeated lessons into reusable capability only when evidence supports it.

Before proposing a Skill:
- Group failures by repeated cause, not by superficial symptom.
- Identify the new instruction, rule, or workflow that would have prevented recurrence.
- Check whether an existing Skill should be updated instead of adding a new one.

For each proposal:
- Include raw evidence references.
- State validation or shadow replay needed before activation.
- Keep generated Skill permissions no broader than the host role.

Never auto-activate a system-generated Skill without review evidence.
