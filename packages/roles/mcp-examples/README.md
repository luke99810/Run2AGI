# MCP 配置样例（不参与默认加载）

本目录的配置**不会被引擎加载**，仅作为编写自定义 MCP 配置的参考。

## alipay.json —— 高风险应用的标注样例

支付宝**不是软件开发工具**，把它放在 `packages/roles/mcp/` 会让
开发工具目录变得名不副实。但它是一个有价值的样例：

**涉及资金操作的 MCP server 应当如何标注。**

| 要点 | 做法 |
|---|---|
| 风险等级 | 在 RoleSpec 侧设 `riskLevel`，不能只靠 MCP 配置 |
| 可见范围 | **不应默认对所有角色可见**——资金工具进入 coder 的工具面没有任何意义，只增加误操作面 |
| 人工审批 | 接入前须确认审批与回滚链路已就绪 |
| 凭据 | `AP_APP_ID` / `AP_APP_KEY` / `AP_PUB_KEY`，来自支付宝开放平台 |

## 要启用本目录中的配置

复制到 `packages/roles/mcp/`，配置凭据，把 `enabled` 改为 `true`。
但请先回答一个问题：

> **如果模型误调用了这个工具，后果可逆吗？**

不可逆的工具需要人工确认点，而不只是一个 `enabled: true`。
